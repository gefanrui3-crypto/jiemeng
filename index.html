解梦 Jiemeng

把任何网页图片，反推成 17 个结构化字段与中英双语提示词。

怎么用

  • 在任意网页悬停图片，点浮出的「解梦 · 反推」
  • 或按 Alt+Shift+X 拖拽框选画面区域
  • 或在图片上右键，选「解梦：反推这张图片」

需要自备接口

  • 本扩展不含开发者服务器，需要你填一个支持图片输入的 OpenAI 兼容接口与 API Key
  • Key 只保存在你自己浏览器的本地存储里，不上传、不同步
  • 图片在本地压缩后直接发送到你自己填的那个接口，没有中间环节
