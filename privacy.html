解梦 Jiemeng · 隐私政策

生效日期：2026-10-30 · 适用版本：0.2.0 及以后 · 最后更新：2026-10-30
一句话说明：解梦没有自己的服务器。你的图片和 API Key 只在你自己的浏览器与你自己填写的接口之间流动， 我们既没有账号系统，也没有任何数据上报。

1. 我们收集什么

不收集。解梦没有后端服务、没有账号体系、没有埋点统计、没有崩溃上报。开发者无法知道你是否安装了它、用了多少次、分析了什么图。

2. 数据存在哪里

全部存在你自己浏览器的 chrome.storage.local 里，卸载扩展即清除，不跨设备同步。

数据内容用途
接口配置接口地址、API Key、模型名调用你自己指定的模型服务
历史记录最近 50 条解析结果、来源网址方便回看；同一张图二次悬停时直接复用，避免重复调用
设置项悬停开关、图片尺寸、温度保持你的使用习惯

API Key 只以明文形式保存在上述本地存储中，不会被发送到开发者或任何第三方，只作为请求头发送给你自己填写的那个接口。

3. 图片去哪了

当你使用图片反推功能时，扩展会在本地把图片压缩、转成 base64，然后直接发送到你在设置中填写的模型接口。这条链路是浏览器直连，不经过任何中间服务器。

该接口由你自己选择并配置（例如 Agnes、OpenAI 或其他兼容服务）。图片在这些服务商处的处理方式，适用该服务商自己的隐私政策，不在本政策覆盖范围内。建议上传前自行判断是否包含敏感信息。

4. 权限用途

权限为什么需要
host_permissions: <all_urls>需要在任意网页上读取图片资源、并截取你框选的画面区域。仅在触发操作时使用。
scripting / activeTab在你框选区域时注入覆盖层、调用标签页截图。
storage保存配置与本地历史。
clipboardWrite把生成的 Prompt 复制到剪贴板。
contextMenus在图片右键菜单里提供入口。
alarms定期清理过期的本地索引。

扩展不读取、不记录你的浏览历史、密码、表单内容或键盘输入。

5. 第三方

本扩展不集成任何分析、广告或追踪 SDK，也不向任何第三方传输数据——除了你自己配置的那个模型接口。

6. 儿童

本扩展不面向 13 岁以下儿童，也不会有意收集其信息。

7. 变更

政策如有修改，会更新本页顶部的日期。涉及数据处理方式的实质变更会在扩展更新说明中提示。

8. 联系

问题或数据相关请求请联系：github.com/gefanrui3-crypto。在该主页提交 Issue 即可，通常一周内回复。

Privacy Policy (English)

Effective: 2026-10-30 · Applies to version 0.2.0 and later

Short version: Jiemeng has no server. Your images and API key only travel between your own browser and the model endpoint you configure. There is no account system and no telemetry.

1. What we collect

Nothing. There is no backend, no account, no analytics, and no crash reporting. The developer cannot tell whether you installed the extension or how you use it.

2. Where data is stored

Everything stays in your browser's chrome.storage.local and is removed when you uninstall the extension. It is never synced across devices.

  • Endpoint settings — endpoint URL, API key, model name, used only to call the service you configured.
  • History — the latest 50 analyses plus their source URLs, so a second hover on the same image does not call the API again.
  • Preferences — hover toggle, image size, temperature.

Your API key is stored locally in plain text and is never sent to the developer or any third party. It is only used as an authorization header for the endpoint you entered.

3. Where your images go

When you analyze an image, the extension compresses and base64-encodes it locally, then sends it directly to the model endpoint you configured. This is a direct browser-to-provider request with no intermediary.

That provider's own privacy policy governs how it handles your images. Please consider whether an image contains sensitive content before analyzing it.

4. Permissions

host_permissions is required to read image resources on any page and to capture the region you select; scripting and activeTab power the selection overlay and tab capture; storage holds settings and local history; clipboardWrite copies the generated prompt; contextMenus adds the right-click entry; alarms prunes stale local indexes.

The extension does not read or record your browsing history, passwords, form input, or keystrokes.

5. Third parties

No analytics, advertising, or tracking SDKs are bundled. No data is transmitted to any third party other than the model endpoint you configure yourself.

6. Children

Not directed to children under 13, and no such data is knowingly collected.

7. Changes

Any change updates the date at the top of this page. Material changes to data handling will be noted in the extension's release notes.

8. Contact

github.com/gefanrui3-crypto — open an issue on that profile. Replies usually within a week.
